# 🚀 CyberDefenseX – Project Preview

> **AI & Blockchain Powered Automated SIEM and SOAR Platform**

CyberDefenseX is a cybersecurity platform that combines traditional SIEM capabilities with blockchain-based log integrity and Explainable AI (XAI). It enables organizations to collect security logs, detect threats using a rule-based engine, automate incident response, and ensure tamper-proof storage of critical security data.

---

## 📌 Highlights

- 📊 Centralized Security Event Monitoring
- ⚡ Automated Rule-Based Threat Detection
- 🤖 Explainable AI (XAI) for security event analysis
- 🔗 Custom Python Blockchain for log integrity
- 🌳 Merkle Tree verification for tamper detection
- 🌐 Leader–Worker decentralized storage architecture
- 📡 HTTP-based block replication
- 📄 Automated PDF report generation
- 📈 Interactive security dashboard

---

## 🔐 Key Innovation

Unlike traditional SIEM platforms that rely on centralized databases, CyberDefenseX stores security evidence using a decentralized blockchain architecture.

Every generated report is hashed and stored inside the blockchain.

This ensures:

- Data Integrity
- Tamper Detection
- Immutable Audit Trail
- Distributed Verification
